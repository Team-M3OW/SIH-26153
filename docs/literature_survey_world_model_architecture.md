# Literature Survey: World-Model / Sequence-Model Architecture for Flat-Vector Network State

Scope: with the network state representation fixed as a **flat per-window feature vector** (not a graph), this survey answers the remaining open design question — which sequence/world-model architecture should learn `P(S_t+1 | S_t)` over that vector and support K-step forward rollout for infiltration-probability forecasting and MITRE ATT&CK stage prediction. It goes deeper than `docs/literature_survey_network_representation.md` §3–4, which only sketched this space; all central claims below (PARD-SSM, DS³M, rSLDS/ssm, NIDS-Mamba) were verified by fetching primary sources, not trusted from search snippets.

---

## 1. Classic sequence models for multivariate flat-vector forecasting

The baseline family: LSTM/GRU/BiLSTM, Temporal Convolutional Networks (TCN), and Transformer/long-sequence forecasters (Informer, Autoformer) applied directly to a `T × D` matrix of windowed flow-feature vectors.

- **Bontemps et al. (2016)** and **Vinayakumar et al. (2019)** — the founding LSTM-for-NIDS papers; stacked LSTM/GRU classifying windows as benign/attack. Reactive, single-step, no forecasting.
- **Chandra, Goyal & Gupta, "Evaluation of Deep Learning Models for Multi-Step Ahead Time Series Prediction" (IEEE Access, 2021, 232 citations)** — head-to-head comparison of RNN, LSTM, BiLSTM, encoder-decoder LSTM, CNN for genuinely multi-step-ahead prediction (not just classification). Finding: **bidirectional and encoder-decoder LSTM variants win** on multi-step accuracy over plain LSTM/CNN — directly relevant if we build an LSTM baseline, since it tells us which LSTM variant to bother with.
- **Wu et al., "NetTrans" (IEEE GLOBECOM 2021)** — Transformer self-attention over flow sequences for traffic classification; a legitimate modern non-recurrent baseline.
- **Relevance caveat.** Most heavily-cited long-sequence Transformer forecasters (Informer, Autoformer, PatchTST-style work) target **long-horizon, often univariate** forecasting (electricity, weather) at much lower sampling frequency than 1-second network windows. Their architectural tricks (frequency-domain decomposition, patch tokenization for month-long horizons) target a different regime than ours (short-horizon K-step, moderate-dimensional multivariate, high frequency) and should not be imported uncritically — noted explicitly so we don't over-engineer on irrelevant complexity.

**Synthesis.** This family is simple, fast to implement, and legitimate as the "plain sequence model, no regime structure" ablation arm (isolating what regime-switching structure buys, per the evaluation design already agreed). It is not, by itself, capable of the PS's explicit forward-rollout / calibrated-probability requirements without extra machinery bolted on (see §4).

## 2. State-space models (S4/S5/Mamba) as the sequence backbone

Structured State-Space Models are the modern, `O(N)`-inference alternative to attention, and — importantly — **already have direct, verified applications to our exact dataset family.**

- **Gu, Goel & Ré, S4 (ICLR 2022)** and the S5/Mamba lineage — linear-complexity sequence layers via structured (diagonal/HiPPO-initialized) state matrices, trained with parallel convolution/scan, inferenced recurrently in `O(1)` per step. Two comprehensive 2025 surveys catalog the field: **"Advancing Intelligent Sequence Modeling: Evolution, Trade-offs, and Applications of State-Space Architectures from S4 to Mamba" (arXiv:2503.18970, 30 votes)** and **"Technologies on Effectiveness and Efficiency: A Survey of State Space Models" (arXiv:2503.11224, 53 votes, Shanghai AI Lab/CMU/Tsinghua)**.
- **"NIDS-Mamba: Lightweight Network Intrusion Detection for IoT Sensor Networks via State Space Models" (Sensors 2026, DOI:10.3390/s26092766, PMC13165659)** — **directly verified, and directly on-target**: evaluated on **NF-UNSW-NB15 and NF-CSE-CIC-IDS2018** (the standardized NetFlow re-derivation of our exact candidate dataset from §1 of the representation survey). Combines dynamic sparse attention with a lightweight Mamba state-space core for joint short-term/long-term pattern learning. Results: **98.32% accuracy, 96.98% F1, AUC 0.9996**, at only **1.12M parameters and 5.4MB peak inference memory** — an order-of-magnitude throughput advantage over Transformer baselines, explicitly positioned for edge/CPU-class deployment. This is strong, verified evidence that a Mamba-class SSM is both accurate and cheap on data essentially identical to what CIC-IDS-2018 will give us.
- **CGP-Mamba** and **IDS-GraphMamba** (2025-2026, Springer/ScienceDirect) — further Mamba-based IDS variants (one graph-augmented), corroborating that Mamba backbones for flow-based IDS is now an active, multi-group line of work, not a one-off result.
- **MambaITD (arXiv:2508.05695)** and **MambaAD / MemMambaAD** — Mamba applied to insider-threat detection and multivariate time-series anomaly *forecasting* respectively, showing the backbone generalizes past pure classification to the sequence-anomaly regime closer to what we need.
- **"Which Deep Learner? A Systematic Evaluation of Advanced Deep Forecasting Models for Network Traffic Prediction" (arXiv:2601.02694, 7 votes, 126 views)** — a 2026 benchmark specifically for network-traffic forecasting (not just IDS classification) across modern architecture families; useful as a second, independent data point beyond NIDS-Mamba for backbone selection once we have real data to test on.

**Synthesis.** For the "plain sequence model" role, **Mamba/SSM beats LSTM and Transformer on cost and, per NIDS-Mamba, on accuracy, on data essentially equivalent to ours** — it should replace BiLSTM as our non-regime deep-learning baseline. It does **not**, however, natively provide a discrete stage variable, an explainable transition structure, or calibrated multi-step probabilities — the same gap LSTM/Transformer have, addressed next.

## 3. Deep generative / latent-variable temporal models — the regime-switching family in depth

This is the crux sub-area: models with an **explicit discrete regime (kill-chain stage) plus continuous latent dynamics**, which is what makes K-step rollout mechanically simple and interpretable rather than an opaque decoder.

### 3a. Foundations
- **Deep Kalman Filters (Krishnan et al. 2015), Variational RNN (Chung et al. 2015), Structured Inference Networks (Krishnan et al. 2017)** — introduce continuous stochastic latents into RNNs via amortized variational inference (VAE-style), the direct ancestor of every model below. No discrete regime; single continuous latent evolves via a nonlinear transition network trained via ELBO maximization.
- **RSSM (Hafner et al., PlaNet 2019)** — the world-model-lineage version: splits the latent into a **deterministic RNN state `h_t`** and a **stochastic Gaussian component `s_t`**, trained by maximizing a multi-step ELBO with **latent overshooting** (training the prior to predict multiple steps ahead directly, not just one) and **KL balancing** (weighting the prior vs. posterior KL terms asymmetrically so the model doesn't collapse to ignoring either the learned dynamics or the observations). No cyber-security instantiation exists (confirmed again this pass via a fresh discover query — the closest 2026 hits are RL/robotics/autonomous-driving/brain-encoding applications, e.g. **RiskWorld** for driving risk and **NeuroWorld** for brain dynamics, not network security).

### 3b. Explicit discrete-regime + continuous-latent models (the family we actually want)
- **Linderman, Miller, Adams, Blei, Paninski & Johnson, "Recurrent Switching Linear Dynamical Systems" (rSLDS, AISTATS 2017, arXiv:1610.08466)** — extends classic Switching LDS by letting the **discrete regime transition depend on the continuous latent state itself** (not just the Markov chain), via a stick-breaking logistic regression made tractable through Pólya-gamma augmentation, enabling efficient block Gibbs sampling. Demonstrated on a synthetic "NASCAR" task and real basketball-trajectory data, showing rSLDS recovers *interpretable, location-triggered* regime switches that a plain SLDS cannot. **Mature, actively maintained open-source implementation**: `github.com/lindermanlab/ssm` (Linderman Lab, Stanford), with a dedicated rSLDS tutorial notebook — the single lowest-implementation-risk option in this entire survey, since we would not be reimplementing inference from scratch.
- **Dong, Seybold, Murphy & Bui, "Collapsed Amortized Variational Inference for Switching Nonlinear Dynamical Systems" (SNLDS, 2020)** — the deep-learning-native switching model DS³M (below) explicitly positions itself against. Uses nonlinear (neural) per-regime transition functions rather than rSLDS's linear-Gaussian ones, at the cost of the interpretable eigenstructure story PARD-SSM later leans on.
- **Xu, Peng & Chen, "Deep Switching State Space Model (DS³M) for Nonlinear Time Series Forecasting with Regime Switching" (International Journal of Forecasting, 2026, arXiv:2106.02329, NUS)** — **verified in depth**: melds an RNN with a nonlinear Switching State-Space Model; discrete regime `d_t` (Markov-governed) and continuous latent `z_t` jointly drive the observation, with an RNN history summary `h_t` improving long-range forecasting via skip connections to observations. Inference is **amortized variational**: marginalize the discrete regime analytically at each step, reparameterize the continuous latent. Benchmarked against GRU, SRNN, DSARF, and SNLDS across 8 real datasets (healthcare, economics, traffic, meteorology, energy) — **beats all of them on forecasting accuracy while producing longer, more realistic regime durations** (a direct, verified rebuttal to the "chaotic switching" failure mode of less-structured switching models). **Official PyTorch code**: `github.com/Sherry-Xu/Deep-Switching-State-Space-Model`, with all 8 datasets' experiment configs — a second, independently mature, well-documented reference implementation.
- **PARD-SSM (arXiv:2604.02299, verified via full-text fetch this pass)** — read in full detail this pass (not just abstract). Confirms and extends what the network-representation survey found: K=4 discrete kill-chain regimes (Normal/Recon/Lateral-Movement.../Exfiltration relabeled as Intrusion in this paper's exact terms), each governing a **regime-specific linear-Gaussian SSM** (`A^(s)`, `Q^(s)`, `C^(s)`, `R^(s)`) over an **8-dim continuous latent** and a **17-dim observation vector** (IAT stats, port-diversity entropy, SYN/ACK ratio, payload entropy, fragment rate, DNS/ICMP rates, HTTP-method entropy — i.e., almost exactly the flat flow+packet feature vector our PS wants us to build). Inference is **structured mean-field variational** (alternating regime-weighted Kalman smoother + HMM forward-backward), giving `O(TK²)` complexity instead of the exact `O(K^T)` — this is the concrete mechanism, not just a claim, and matches classical Ghahramani & Hinton (2000) variational-switching-SSM theory rather than a deep amortized encoder. **K-step rollout is literally `γ̂_{t+τ} = (Πᵀ)^τ γ_t`** — matrix-power on the learned regime-transition matrix, an operation any judge can be shown on a whiteboard. Reported: F1 0.982 vs. 0.744 BiLSTM on CICIDS2017, **≈8-minute predictive lead time** (the only system in its own benchmark with `EDM ≠ None`), **<1.2ms/flow on CPU, no GPU**. **Caveat found on this closer read**: authors are a small Indian university team (VTU Belagavi) plus a named hobbyist research collective ("Aliens on Earth"), and the paper states *"Specific model parameter values are protected under a pending Indian patent"* even while claiming full reproducibility — meaning we should treat this as **prior art to reimplement from the fully-specified equations in the paper** (all update equations are given in closed form — this is unusual and valuable, most papers don't give this much of the math), not as a repo we should literally clone and claim as our own base, both for IP-cleanliness and because independent reimplementation is itself a defensible technical achievement for the hackathon.
- **Newer 2026 refinements found this pass** (not in the previous survey): **"End-to-End Identifiable and Consistent Recurrent Switching Dynamical Systems" (arXiv:2605.06315)** — addresses a known rSLDS weakness (non-identifiability of the learned regimes) with an end-to-end identifiable formulation; **"Time-Varying Deep State Space Models for Sequences with Switching Dynamics" (arXiv:2605.15311)**; **"Identifiable Markov Switching Models with Instantaneous Effects and Exponential Families" (arXiv:2606.02231)**. These are recent enough (May–June 2026) that they represent genuine frontier improvements on the exact family we're proposing, though none has been applied to cyber telemetry yet — worth citing as "this is where the technique is still actively improving," not as something to implement under time pressure.

**Synthesis.** The regime-switching family is not a one-off — it is a real, multi-decade lineage (Ghahramani & Hinton 2000 → Linderman et al. 2017 rSLDS → Dong et al. 2020 SNLDS → Xu et al. 2026 DS³M → PARD-SSM 2026 cyber-specific instantiation) with **two independently mature, MIT/BSD-licensed-style open-source codebases** (`lindermanlab/ssm`, `Sherry-Xu/Deep-Switching-State-Space-Model`) we can build on directly, plus one closely-matching cyber-specific paper (PARD-SSM) whose math is fully specified in closed form even though its exact repo shouldn't be treated as ours to lift.

## 4. Probabilistic, calibrated multi-step forecasting

The PS wants a **time-series probability score**, not a point prediction — this section covers how to make that calibrated.

- **Wen, Torkkola & Narayanaswamy, "A Multi-Horizon Quantile Recurrent Forecaster" (arXiv 2017, 531 citations)** — MQRNN: RNN encoder + direct multi-horizon quantile decoder, the architecture Amazon's DeepAR-adjacent line descends from. Standard reference for "bolt quantile output onto any RNN."
- **Chandra & Cheung et al., "Quantile deep learning models for multi-step ahead time series prediction" (Applied Soft Computing 2025 / arXiv 2024)** — modern re-evaluation of quantile-loss deep learning specifically for multi-step forecasting under volatility, confirms quantile heads add calibrated uncertainty "for free" (no accuracy loss) on top of any point forecaster.
- **Conformal prediction for time series** — a cluster of methods giving **distribution-free, finite-sample coverage guarantees**, which matters because our attack-window data is non-stationary and far from i.i.d.: **EnCQR (Jensen et al., IEEE TNNLS 2022, 86 citations)** — ensemble conformalized quantile regression for non-stationary/heteroscedastic series; **Copula Conformal Prediction (Sun et al., arXiv 2022, 38 citations)** — multivariate, multi-step coverage via copulas; **AEnbMIMOCQR (Sousa et al., arXiv 2022)** — adaptive, multi-input-multi-output conformalized quantile regression for H-step-ahead heteroscedastic forecasting, with public code; **nmtCP (Schlembach et al., Machine Learning 2025)** — non-exchangeable multi-target CP for multivariate multi-step forecasts with provable miscoverage bounds; **Zaffran et al., "Adaptive Conformal Predictions for Time Series" (ICML 2022)** — Adaptive Conformal Inference (ACI), online-correcting the target miscoverage rate itself as regime shifts occur, is the key building block for the next paper.
- **"Adaptive Regime-Switching Forecasts with Distribution-Free Uncertainty: Deep Switching State-Space Models Meet Conformal Prediction" (NeurIPS 2025 Workshop, arXiv:2512.03298, verified in full)** — **the single most directly useful paper in this section**: wraps **DS³M (§3b) with Adaptive Conformal Inference / AgACI** to get calibrated online prediction intervals that remain valid across regime transitions, benchmarked against S4, MC-Dropout GRU, sparse GP, and change-point-detection baselines. Finding: **DS³M + AgACI gives the best calibration on the regime-heavy datasets** (Lorenz, unemployment) while S4 alone gives tighter intervals on smooth, low-noise series — i.e., the conformal wrapper is architecture-agnostic and composes cleanly on top of *any* backbone, including a regime-switching SSM. This is a ready-made recipe: **take PARD-SSM's point/regime forecast, wrap it in the same ACI layer this paper uses**, and we get calibrated K-step probability bands with a proof-backed coverage guarantee, essentially for free.

**Synthesis.** Quantile/conformal methods are the standard, well-validated way to answer "how confident is this probability score" for any of the backbones in §1–3, and — critically — **conformal wrapping composes naturally with a switching-SSM rather than competing with it** (2512.03298 demonstrates exactly this combination). This resolves what would otherwise be a gap in PARD-SSM's own design (it reports point regime-posteriors, not calibrated intervals).

## 5. Direct applications to cyber telemetry *forecasting* (not just classification), 2024–2026

- **PARD-SSM (§3b)** and **StageFinder (arXiv:2603.07560, verified in the prior survey)** remain the two closest full-system matches.
- **"A Predictive Neural Network Architecture for Early Detection of Low-Rate Cyberattacks" (arXiv:2606.18771, June 2026)** — targets exactly the PS's "slow reconnaissance scan designed to evade flow-based thresholds" scenario (Low-Rate DoS/LDoS on IoT), with a predictive (not reactive) architecture — worth reading closely once we're implementing the "stealthy attack" stress-test from the earlier evaluation-design discussion.
- **"Predicting Tail-Risk Escalation in IDS Alert Time Series" (arXiv:2601.14299, Jan 2026)** — forecasts *escalation* of already-triggered IDS alerts into high-severity outcomes, a slightly different framing (alert-stream forecasting rather than raw-telemetry forecasting) but directly on-topic for "will this get worse."
- **"Forecasting Attacker Actions using Alert-driven Attack Graphs" (arXiv:2408.09888, TU Delft/Twente, 2024)** — predicts next attacker action from a sequence of IDS alerts via attack-graph structure; an alert-level (not flow-level) analogue of what we're building, useful for cross-checking our MITRE-stage output design against a non-SSM approach.
- **"ChainWatch" (arXiv:2607.19432, July 2026)** — kill-chain-aligned sequential detection, but for MCP-based AI-agent systems, not network traffic; out of scope for our representation but confirms the "kill-chain-aligned sequential model" framing is being actively adopted as a template pattern across security subfields in 2026, which is a point worth making in our architecture doc's related-work framing.

**Synthesis.** The frontier as of September 2026 has meaningfully moved toward *predictive* (not just detective) framings — this validates the PS's core premise as a live, current research direction, not a hypothetical one, and gives us several fresh (2024–2026) citations beyond the classic 2016–2020 LSTM-IDS lineage.

## 6. Practical / hackathon-timeline considerations

| Architecture | Open-source code? | Maturity | GPU required? | Reimplementation effort |
|---|---|---|---|---|
| Plain LSTM/BiLSTM | Trivial (any DL framework) | Very mature | No (small models) | Very low |
| Mamba / S4 backbone | `state-spaces/mamba` official repo; `mamba-ssm` pip package | Mature, widely used since 2023 | Optional (fast on CPU too for small dims) | Low — drop-in sequence layer |
| rSLDS | `lindermanlab/ssm` — actively maintained Stanford lab package, tutorials included | Mature (since 2017, still maintained) | No | Low — library handles inference |
| DS³M | `Sherry-Xu/Deep-Switching-State-Space-Model` — official, 8 dataset configs included | Medium (single-paper repo, but complete) | Optional | Medium — adapt to our data/regime count |
| PARD-SSM (as specified) | `github.com/prakulhiremath/PARD-SSM` claimed, but core parameters patent-flagged | Low (single hackathon-style paper) | No — explicit design goal | Medium — reimplement from paper's closed-form equations, don't clone verbatim |
| Conformal wrapper (ACI/AgACI) | Public code cited in Zaffran et al. and Sousa et al. (AEnbMIMOCQR repo) | Mature | No | Low — post-hoc wrapper, framework-agnostic |

**Data/compute reality check:** regime-switching SSMs (rSLDS, DS³M, PARD-SSM-style) need comparatively **little labeled data** relative to a from-scratch deep sequence model, because the linear-Gaussian-per-regime structure is a strong inductive bias — directly relevant given our labeled multi-stage-attack sequences (CIC-IDS-2018 Infiltration/Bot days) will be a small fraction of total traffic. Pure LSTM/Transformer/Mamba baselines will need more data and are more prone to overfitting the small attack class, reinforcing the case for the regime-structured approach as primary rather than fallback.

## Recommendation

**Implement a PARD-SSM-style regime-dependent switching linear-Gaussian state-space model as the primary world model, wrapped with an Adaptive Conformal Inference layer for calibrated K-step probability output, benchmarked against a three-rung baseline ladder that isolates exactly what each design choice buys.**

This deeper dive **confirms and sharpens** rather than overturns the earlier survey's direction, with two concrete additions:

1. **Core architecture — regime-switching SSM, PARD-SSM's specific instantiation, reimplemented from its closed-form equations (§3b) rather than cloned:** discrete regime `s_t ∈ {Normal, Recon, Lateral-Movement, Exfiltration}` (or our 5-stage PS mapping), each governing a regime-specific linear-Gaussian SSM over a compact (~15–20 dim) flow+packet observation vector, inferred via structured mean-field variational EM (Kalman smoother + HMM forward-backward, `O(TK²)`). This is the only architecture in the entire survey that gives K-step rollout as a **literal closed-form operation** (`Π^τ`) rather than an autoregressive decoder, runs on CPU at <1.2ms/flow (real-time-capable, satisfies the PS's offline/local-demo requirement trivially), and has explainability **built into the generative model itself** rather than needing a post-hoc approximation — the strongest possible answer to "black-box outputs are not acceptable."
2. **New refinement this pass — add an Adaptive Conformal Inference (ACI/AgACI) layer on top (§4)**, following arXiv:2512.03298's demonstrated recipe of wrapping a regime-switching SSM's point/regime forecast in conformal calibration. This is the one concrete gap in PARD-SSM itself (it reports regime posteriors, not coverage-guaranteed intervals) and the fix is architecture-agnostic, cheap, and has public reference code — directly strengthens our "time-series probability score" deliverable with a real statistical guarantee we can state precisely in the architecture doc, rather than an uncalibrated softmax.

**Baseline ladder for the mandated benchmark (per PS + the earlier evaluation-design discussion), each isolating one added capability:**
- **Rung 0 (mandated):** logistic regression on flat windowed features — no temporal structure at all.
- **Rung 1:** Mamba-based sequence classifier (following NIDS-Mamba's proven NF-CSE-CIC-IDS2018 configuration, §2) — adds temporal structure, no regime/rollout, replaces a plain BiLSTM baseline since it is cheaper and, per verified results, more accurate on data essentially identical to ours.
- **Rung 2 (ours):** PARD-SSM-style regime-switching SSM + ACI calibration — adds explicit regime structure and calibrated forward rollout on top of Rung 1's temporal modeling.

If Rung 2 beats Rung 1 by a meaningful margin (as PARD-SSM's own ablation — F1 0.982 full system vs. 0.680 single-regime Kalman filter — suggests it should), that delta is direct, defensible evidence that **explicit kill-chain regime structure**, not just "having a sequence model," is what the PS's "genuine dynamics learning, not memorized classification" requirement is actually asking for — which is the single strongest claim we can put in the architecture document and the demo narrative.

**Implementation risk note:** two of the three architecture families here (rSLDS via `lindermanlab/ssm`, DS³M via `Sherry-Xu/Deep-Switching-State-Space-Model`) have mature, borrowable open-source inference code even though we are following PARD-SSM's specific model design — if the from-scratch structured-VI implementation proves too time-consuming under hackathon pressure, `lindermanlab/ssm`'s rSLDS fitting code is the concrete fallback path to a working regime-switching model without writing custom variational inference from zero.
